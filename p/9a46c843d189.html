📊 要加多少？FY2026 → FY2027 每个地区每月需增加

对比去年整年实际（FY2026 = Oct'25–Sep'26）与今年目标（FY2027），算出每个地区每个月要多做多少粒（Varta + Energizer）。
Year-on-year: last full year's actual vs this year's target → how many more units each region needs per month.
「每月要增加」= (FY2027 目标 − FY2026 实际) ÷ 12（年度平均）。百分比高≠粒数多：看绝对粒数才知道压力在哪。

📅 每个月实际要增加多少？（对比去年同月）

年度÷12 只是平均。实际上每个月的目标不同、去年同月的实际也不同（有淡旺季），所以每个月要加的粒数不一样。下表 = 每区、每月对比去年同一个月要多做多少粒。
The ÷12 average hides seasonality — each month's target and last-year actual differ. This grid shows, per region per month, how many more units vs the same month last year.
需增加 = 该月 FY2027 目标 − 去年同月实际。绿=要加,红=去年同月比目标还高(不用加)。
